# Шрифт заголовков — Benzin

Файлы шрифта в репозиторий не входят: лицензия разрешает использовать Benzin на сайте,
но не распространять сами файлы.

Чтобы собрать сайт, положите в папку `src/fonts/Benzin font/` два файла:

- `Benzin-Regular.woff2` — заголовки на сайте (`src/app/layout.tsx`);
- `Benzin-Regular.ttf` — картинка для соцсетей (`src/lib/og-fonts.ts`).

Без них `npm run build` и `npm run dev` остановятся с ошибкой: файл шрифта не найден.
